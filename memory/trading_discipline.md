# 交易纪律 · 铁律全书 v3

## Rule 1：开仓五条

| # | 条件 | 检查 |
|:---:|------|:---:|
| 1.1 | 增强评分 ≥ 6 | DKX 不下降 + A1X 3日趋势 ↑ |
| 1.2 | 箱体位置 < 85% | 不在顶部接盘 |
| 1.3 | 多周期一致 | 周线趋势不向下 |
| 1.4 | 资金足够 | 现金 ≥ 所需资金 × 1.2 |
| 1.5 | 单票仓位 ≤ 35% | 总资产 × 35% |

**缺一条 → 不开仓。**

## 五条永久操作规范

### 规范 1：止损 = 市价单
Rule 2.1 触发时 → 撤限价单 → 市价离场。在跌市中限价单永远挂在墙上。

### 规范 2：集合竞价两步走
- 9:15-9:20：观察虚拟成交价 + 匹配量
- 9:20：方向锁定，挂单确保成交

### 规范 3：查持仓 = 三件套
每次心跳必查：
1. 最新价 + 涨跌幅
2. 分时量能（缩量 or 放量？）
3. 买一/卖一挂单比（>2 有人接，<0.5 没人要）

### 规范 4：每日品种池增量
早报第一步 → 板块成交额 TOP10 → 不在池的成分股强制入库。

### 规范 5：复盘五件套
每笔交易：
1. 价格 + 时间 + 执行方式
2. 成交时刻盘口状态
3. 成交前后 30 分钟量能变化
4. 板块内联动情况
5. 系统建议 vs 实际偏差
