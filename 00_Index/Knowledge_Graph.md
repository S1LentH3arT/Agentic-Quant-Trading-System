# 股市全知识库索引 (Knowledge Graph)

本知识库旨在为 Hermes 大模型提供结构化的股市理论、分析方法及实战案例。

## 知识体系地图
- **01_Foundations**: 底层逻辑 $\rightarrow$ 宏观经济 $\rightarrow$ 金融基础 $\rightarrow$ 交易机制
- **02_Analysis_Methods**: 分析工具 $\rightarrow$ 基本面 (价值) $\rightarrow$ 技术面 (趋势) $\rightarrow$ 量化 (统计)
- **03_Trading_Strategies**: 交易方案 $\rightarrow$ 价值投资 $\rightarrow$ 成长投资 $\rightarrow$ 趋势跟踪 $\rightarrow$ 对冲套利
- **04_Psychology_Risk**: 软技能 $\rightarrow$ 交易心理 $\rightarrow$ 风险控制 (仓位管理)
- **05_Case_Studies**: 实战复盘 $\rightarrow$ 传奇人物 $\rightarrow$ 历史周期 $\rightarrow$ 单笔交易分析
- **06_Market_Specifics**: 市场差异 $\rightarrow$ 美股 $\rightarrow$ A股 $\rightarrow$ 数字资产/商品
- **07_Information_Channels**: 实时情报 $\rightarrow$ 财联社 (国内) $\rightarrow$ 金十数据 (宏观) $\rightarrow$ X (全球Alpha/情绪)

## 调用建议
对于 LLM 检索，请优先在 `00_Index` 中查找相关模块，然后进入对应子目录读取原子化 Markdown 文件。
